# Лабораторні роботи з баз даних

- `lab01-report.md` - звіт з ЛР1, PostgreSQL у Supabase;
- `Lab02_SQL/lab02-report.md` - звіт ЛР2 зі складними SQL-запитами;
- `lab03-report.md`, `Lab03_SQL/` - ЛР3, зміна даних і транзакції;
- `Lab04/` - ЛР4, бібліотека, консольний CRUD і вебзастосунок Flask;
- `lab05-report.md`, `Lab05_SQL/` - ЛР5, індекси, ролі, обслуговування;
- `Lab06_Mongo/` - ЛР6, MongoDB;
- `Lab07_Blog/` - ЛР7, блог на MongoDB.

Знімки екрана лежать у каталогах `screenshots` поруч із відповідним звітом.
Лабораторні 1 і 2 виконані в Supabase SQL Editor. Лабораторні 3-5 використовують
контейнер `library-pg` (PostgreSQL 16). Лабораторні 6 і 7 використовують replica set
`rs0` з контейнерів `library-mongo`, `library-mongo-2` і `library-mongo-3`.
