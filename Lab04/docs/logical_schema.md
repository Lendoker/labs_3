# Логічна схема бази «Бібліотека»

Схема відповідає третій нормальній формі.

- **1НФ.** У кожній комірці одне значення: немає списків авторів чи телефонів в одному полі.
- **2НФ.** Первинні ключі всіх таблиць атомарні (`author_id`, `book_id`, `reader_id`, `loan_id`, `reservation_id`, `publisher_id`, `genre_id`), тому неключові атрибути не залежать від частини ключа.
- **3НФ.** Жанр, видавництво й автор винесені в окремі таблиці. Назва жанру не зберігається в `books` і не залежить транзитивно від `book_id` через інший неключовий атрибут. Статус читача описує читача, а не видачу.

## Таблиці

| Таблиця | Первинний ключ | Зовнішні ключі | Обмеження |
| --- | --- | --- | --- |
| `genres` | `genre_id` | - | `name` UNIQUE NOT NULL |
| `publishers` | `publisher_id` | - | `name` UNIQUE, `country` NOT NULL |
| `authors` | `author_id` | - | рік народження в діапазоні, унікальність ПІБ і року |
| `books` | `book_id` | `author_id` RESTRICT, `publisher_id` SET NULL, `genre_id` SET NULL | ISBN UNIQUE, `available_copies <= total_copies`, рік видання |
| `readers` | `reader_id` | - | email і номер картки UNIQUE, статус Active/Blocked/Inactive |
| `loans` | `loan_id` | `book_id`, `reader_id` RESTRICT | `due_date > loan_date`, дата повернення не раніше видачі |
| `reservations` | `reservation_id` | `book_id`, `reader_id` CASCADE | статус Active/Fulfilled/Cancelled/Expired |

## Зв'язки

- Автор - книга: один до багатьох. У книзі один основний автор.
- Видавництво - книга: один до багатьох. Видавництво можна видалити, у книги лишається NULL.
- Жанр - книга: один до багатьох.
- Читач - видача і читач - бронювання: один до багатьох.
- Книга - видача: один до багатьох. Книгу з історією видач видалити не можна (`RESTRICT`).
- Книга - бронювання: один до багатьох, видалення книги прибирає бронювання (`CASCADE`).

Службові таблиці `audit_log`, `books_versions`, `scheduled_operations`, `backup_points`, `app_users`, `activity_log` не змінюють нормальну форму предметних відношень: вони фіксують історію, версії, відкладені дії та облікові записи застосунку.
