# Звіт з лабораторної роботи №1
**Тема:** Розробка консольних застосунків мовою C#  
**Виконав:** Пінкевич Артем Романович  
**Група:** ІПЗ-32  
**Рівень:** високий — усі п'ять програм об'єднано спільним меню

## Мета роботи
Навчитися розробляти консольні застосунки мовою C#, працювати з введенням і
виведенням даних, циклами, умовами, колекціями та математичними методами.

## Програмне забезпечення
- .NET SDK 9.0 або новіший;
- Visual Studio / Visual Studio Code;
- Windows Terminal або вбудований термінал.

## Хід роботи
Створено проєкт `Lab01_CSharp`. Запуск:

```bash
dotnet run --project Lab01_CSharp/Lab01_CSharp.csproj
```

Після запуску програма показує меню з п'ятьма пунктами.

### 1. Таблиця функції f(x) = x²
Користувач вводить `x_min`, `x_max` і додатний крок `dx`. Цикл формує
таблицю значень. Додатково обчислюються мінімум, максимум, середнє значення
та кількість додатних/від'ємних результатів.

### 2. Таблиця функції f(x1, x2) = x1² + e^x2
Використано вкладені цикли: зовнішній перебирає `x1`, внутрішній — `x2`.
Значення експоненти обчислюється методом `Math.Exp`.

### 3. Факторіал і сума факторіалів
Для `n` від 1 до 20 обчислюються `i!` та накопичувальна сума
`1! + 2! + ... + n!`. Тип `long` обмежує максимальне значення 20.

### 4. Досконалі числа
Для кожного числа діапазону формується список власних дільників. Число
виводиться, якщо сума дільників дорівнює самому числу.

### 5. Аналіз тексту
Програма підраховує символи, слова, речення, українські голосні та
приголосні. Результат виводиться у форматованій таблиці.

## Контрольний приклад
Для `n = 5` програма виводить:

```text
1! = 1
2! = 2
3! = 6
4! = 24
5! = 120
1! + ... + 5! = 153
```

Для діапазону `1..10000` знаходяться досконалі числа `6`, `28`, `496`,
`8128`.

## Висновок
Створено єдиний консольний застосунок C# зі спільним меню. Закріплено роботу
з циклами, умовними операторами, рядками, списками, математичними функціями
